# Akalus Global Website - Project Guidelines

This file is created to persist the context of the project so that AI agents do not have to re-analyze everything from scratch.

## Project Context
- **Name**: Akalus Global Website
- **Tech Stack**: Vanilla HTML5, CSS3, JavaScript (No frameworks like React or Angular).
- **Architecture**: Single page (or multi-page static) website.
- **Main Files**: `index.html`, `styles.css`, `script.js`.

## Agent Instructions
- **Do not** look for React components (`.tsx`, `.jsx`) or Node.js backend files unless explicitly added.
- **Do not** use `npm` packages for the frontend UI unless imported via CDN, because this is a static site.
- When adding features, use CDNs (e.g., GSAP for animations, Firebase for Auth/DB).
- Maintain the premium, professional, and trending design language. Use modern CSS (Glassmorphism, clean typography, smooth transitions).
